# Instant Virtual Worlds

## Goal
Create virtual worlds using only runtime generated parameters. 
- No pre-baking of world geometry
- No stutters, pauses
- Rendering at 60 FPS
- Earth sized
- Detail from whole globe to a single grass blade

## Technology
No game engine. This is a research project, not a game. The more I have to do myself, the more I learn.
- C#
- SharpDX COM+ Wrapper for DirectX11
- HLSL
- Open Source models 

## Techniques
- Adaptive Tesselation Mesh
- Toroidal Model Map
- Distance Fields
- Urban Landscape Modelling
